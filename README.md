# MOMSAT Web

Next.js 15 + React 19 web app for Persian live-TV discovery, playback and catalog administration.

## Included
- RTL Persian discovery homepage.
- Live channel catalog with search and category filters.
- Channel detail pages with all normalized metadata and source variants.
- HLS playback using native browser HLS or hls.js.
- Admin control center with catalog statistics and `Fetch + Sync`.
- PostgreSQL schema through Prisma: `Category`, `Channel`, `Source`.
- Pluggable catalog source adapters with optional failure isolation.

## Run
```bash
npm install
cp .env.example .env
npx prisma generate
npx prisma db push
npm run seed
npm run dev
```

## Catalog ingestion

MOMSAT now supports multiple independent catalog adapters. A missing or failing optional adapter does not prevent the remaining sources from syncing.

### 1. ParsaTV public directory
```env
SOURCE_PARSATV_ENABLED="true"
SOURCE_PARSATV_INDEX_URL="https://www.parsatv.com/"
```
The adapter discovers public channel detail pages and extracts publicly exposed HLS/stream/embed URLs. It does not bypass authentication or access controls.

### 2. PersianTVLive public directory
```env
SOURCE_PERSIANTVLIVE_ENABLED="true"
SOURCE_PERSIANTVLIVE_INDEX_URL="https://www.persiantvlive.com/"
```
It uses the same normalized discovery pipeline and isolates individual channel-page failures.

### 3. PakhshZende public directory
```env
SOURCE_PAKHSHZENDE_ENABLED="true"
SOURCE_PAKHSHZENDE_INDEX_URL="https://pakhshzende.com/tv-channels/"
```
The adapter discovers `/tv-channel/` pages and extracts publicly exposed stream/embed URLs.

### 4. Generic M3U importer
```env
SOURCE_M3U_ENABLED="true"
SOURCE_M3U_URLS="https://example.com/playlist.m3u,https://example.com/another.m3u"
```
Multiple URLs can also be separated by newlines. `EXTINF`, `tvg-logo` and `group-title` metadata are normalized into the common `Channel` model.

### 5. Official broadcaster feeds
```env
SOURCE_OFFICIAL_ENABLED="true"
SOURCE_OFFICIAL_URLS="https://example.com/channels.json,https://example.com/channels.m3u"
```
Each configured endpoint may return the normalized JSON post format or an M3U playlist. Only feeds that the deployment is authorized to consume should be configured.

### 6. Optional encrypted mytvsat feed
The encrypted `mytvsat` feed is disabled by default and is completely optional:
```env
SOURCE_ENCRYPTED_ENABLED="false"
```
To enable it, all upstream credentials must be supplied in the deployment environment:
```env
SOURCE_ENCRYPTED_ENABLED="true"
SOURCE_ENCRYPTED_URL="https://raw.githubusercontent.com/mytvsat/webservice/main/v2/posts"
SOURCE_AES_KEY_HEX="..."
SOURCE_AES_IV_HEX="..."
```
The AES key and IV are upstream credentials. They are not generated by MOMSAT and are not committed to the repository. Missing credentials produce an `unconfigured` adapter status rather than failing the whole sync.

## Discovery controls
```env
SOURCE_SITE_MAX_CHANNELS="250"
SOURCE_SITE_CONCURRENCY="6"
SOURCE_FETCH_TIMEOUT_MS="15000"
SOURCE_HTTP_USER_AGENT="MomSatCatalog/1.0"
```
These controls prevent an adapter from crawling an unbounded number of pages and make the ingestion workload predictable.

`ADMIN_TOKEN` remains a MOMSAT-side secret used to protect the admin sync endpoint.
