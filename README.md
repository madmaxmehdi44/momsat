# MOMSAT Web

Next.js 15 + React 19 web app for Persian live-TV discovery, playback and catalog administration.

## Included
- RTL Persian discovery homepage.
- Live channel catalog with search and category filters.
- Channel detail pages with all normalized metadata and source variants.
- HLS playback using native browser HLS or hls.js.
- Admin control center with catalog statistics and `Fetch + Sync`.
- PostgreSQL schema through Prisma: `Category`, `Channel`, `Source`.
- Pluggable catalog source adapters, including an optional AES-256-CBC + GZIP encrypted `mytvsat` adapter.

## Run
```bash
npm install
cp .env.example .env
npx prisma generate
npx prisma db push
npm run seed
npm run dev
```

## Catalog ingestion

The encrypted `mytvsat` feed is optional. The application must start and the catalog sync endpoint must remain usable when its AES credentials are absent.

To disable the adapter explicitly:
```env
SOURCE_ENCRYPTED_ENABLED="false"
```

To enable it, set all of the following in the deployment environment where access to the upstream payload is authorized:
```env
SOURCE_ENCRYPTED_ENABLED="true"
SOURCE_ENCRYPTED_URL="https://raw.githubusercontent.com/mytvsat/webservice/main/v2/posts"
SOURCE_AES_KEY_HEX="..."
SOURCE_AES_IV_HEX="..."
```

The AES key and IV are upstream credentials; they are not generated by MOMSAT and are not committed to the repository. If they are unavailable, the `mytvsat` adapter is reported as `unconfigured` and skipped rather than causing the whole ingestion pipeline to fail.

`ADMIN_TOKEN` remains a MOMSAT-side secret used to protect the admin sync endpoint.
